Cleaner

The package's cleanup bag. Add what must be released, and Destroy releases it all in reverse order: instances, connections, threads, functions, and anything with Destroy or Disconnect. Your own cleanup helper works with the package too, as long as it calls Destroy.

Releases everything, newest first, and leaves the cleaner usable. An object that errors on release is warned about and the rest are still released.
