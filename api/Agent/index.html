Agent

The running AI: what every Enter, Update, Exit, When and Input function receives. Made by Builder:Build or VluxyAI.NewAgent, started with Agent:Start, and taken apart with Agent:Destroy. See Types.Agent for the fields.

Functions​

new​

</>
Agent.new(definition: AgentDefinition) → Agent

Builds an agent from a definition. Blackboard and Data initial values are deep-copied, so one definition can make many agents. The agent is not running until Agent:Start.

Errors

TypeDescription
stringThe definition failed [Validate.Definition].

StrictBlackboard​

</>
Agent.StrictBlackboard(
blackboard: Blackboard,--

The real table; initial keys count as known.

name: string--

For the warning.

) → Blackboard--

A view that warns once per key that reads as a misspelling of a known one.

What StrictBlackboard on the definition installs. Writes go through and make the key known; a read of an unknown key whose spelling is within two edits (or a case change) of a known key warns, naming both. Any other unknown read is an ordinary nil, since memory keys are nil most of the time by design.

Pause​

</>
Agent.Pause(self: Agent) → ()

Freezes the agent: ticks stop, so senses, navigator and brain stand still; the mover halts; timers and TimeInState hold. For a cutscene, a jumpscare, or a director backing an enemy off. The navigator keeps its target and re-plans on the first tick after Agent:Resume. Does nothing when not running or already paused.

Resume​

</>
Agent.Resume(self: Agent) → ()

Undoes Agent:Pause. Every running timer and TimeInState are pushed forward by the time spent paused, so a timer with two seconds left still has two seconds left.

Teleport​

</>
Agent.Teleport(
self: Agent,
position: Vector3--

Where the body goes: the root or pivot position, not a floor position.

) → ()

Puts the agent somewhere else at once and forgets the current target, so the next MoveTo plans from the new place. Uses the mover's optional Teleport, else pivots the entity. For a stalker that vanishes and reappears out of sight; pair it with Perception.SeenByAnyone.

IsNew​

</>
Agent.IsNew(
self: Agent,
key: string--

A blackboard key, usually a memory such as HeardAt or HeardSoundAt.

) → boolean--

true while Blackboard[key] is non-nil and differs from the value last acknowledged.

"Is there something here I have not dealt with yet?" A transition that investigates every new noise reads agent:IsNew("HeardAt") and calls Agent:Acknowledge when it acts, so the same noise is not investigated twice. When.New does both in one predicate.

SetSpeed​

</>
Agent.SetSpeed(
self: Agent,
speed: number,--

Studs per second, before the speed scale.

seconds: number?--

Ramp to it over this long instead of at once, so a lunge builds and a stop settles.

) → ()

The agent's base speed: what a state asks for. The mover gets speed times the speed scale (Agent:SetSpeedScale), so a crowd ease or a slow-motion effect layered on top survives a state changing its own speed. With seconds the base speed moves there over the agent's ticks; a new SetSpeed replaces the ramp. Does nothing without a mover.

SetSpeedScale​

</>
Agent.SetSpeedScale(
self: Agent,
scale: number--

A multiplier on the base speed; 1 is none, 0.5 half speed.

) → ()

Layered on top of whatever Agent:SetSpeed asked for, and kept across state changes. The Neighbours sense eases through this; a director or a stun can too.

GetSpeed​

</>
Agent.GetSpeed(self: Agent) → number--

Destroy​

</>
Agent.Destroy(self: Agent) → ()

Exits the current state, stops moving, and destroys the navigator, every sense, the mover and the pathfinder that have a Destroy, then fires Destroyed. Safe to call twice. The entity model is left alone; it is yours.
