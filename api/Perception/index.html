Perception

The helpers the built-in senses are made of, and the place to start when writing your own. A Types.Sense is any table with Tick; the work inside one is usually "who could I be looking at" (AliveRoots), "is it in front of me" (InCone), "is anything in the way" (LineOfSight), "which is nearest" (SortByDistance), and this module answers each of those on its own.

Everything here is about targets: Perception.HumanoidOf takes a root a sense wrote to the blackboard and finds that character's humanoid. The agent's own humanoid is agent.Entity:FindFirstChildOfClass("Humanoid"), and the two look alike in code, so name the variable.

Targets on every built-in sense defaults to Perception.AliveRoots, and Ignore on Sight defaults to Perception.IgnoreList. A brain that acts on a target root a sense wrote to the blackboard reaches the rest of the character through Perception.CharacterOf and Perception.HumanoidOf.

Everything that takes a part reads it duck-typed, so a spec can pass plain tables.

Properties​

HIDDEN_ATTRIBUTE​

</>
Perception.HIDDEN_ATTRIBUTE: "AI_HIDDEN"

The attribute name that hides a character from every sense: set it to true on the character (or on its root) while the player is in a locker, under a bed, or otherwise out of the game's sight rules, and Perception.AliveRoots leaves them out until it is cleared.

LIGHT_TAG​

</>
Perception.LIGHT_TAG: "AI_LIGHT"

The CollectionService tag a light must carry for Perception.LightAt to count it.

AliveRoots​

</>
Perception.AliveRoots() → {BasePart}--

The HumanoidRootPart of every player whose character is alive and not hidden.

Every player character with a Humanoid whose Health is above zero, by its root, minus the ones hidden with Perception.HIDDEN_ATTRIBUTE. The default Targets of every sense, so hiding a player once hides them from Sight, Proximity and Watched together. Takes no arguments, so it can be a Targets function as it is.

AllAliveRoots​

</>
Perception.AllAliveRoots() → {BasePart}--

Every alive player root, hidden ones included.

For the checks a hidden player still takes part in: Perception.SeenByAnyone uses it, since a player inside a locker can still see out of it.

LineOfSight​

</>
Perception.LineOfSight(
from: Vector3,
to: Vector3,
ignore: {Instance},--

What the ray passes through.

allow: Instance?,--

What the ray may hit and still count as clear, usually the target's own model.

seeThrough: ((part: BasePart) → boolean)?--

Parts this returns true for do not block; the ray is cast again past them, up to eight times.

) → boolean

Is the straight line from from to to clear? true when the ray hits nothing, or hits allow or something under it, which is how a target's own body does not block sight of it. Without seeThrough, anything else the ray hits blocks, glass included; pass Perception.Transparent or your own rule to look past it.

CountWalls​

</>
Perception.CountWalls(

Hits within this many studs of to do not count, so a noise inside a body is not walled off by that body. Default 2.

) → number--

How many distinct parts the straight line crosses, up to limit.

How many walls stand between a sound and a listener. Hearing and Sounds multiply the loudness by Occlusion once per wall.

LightAt​

</>
Perception.LightAt(
position: Vector3,
ambient: number?--

Light everywhere, added before the clamp. 0 is pitch black where no light reaches. Default 0.

) → number--

The light level at position in [0, 1]: ambient plus every tagged light's Perception.LightContribution, clamped.

How lit a spot is, from the lights tagged Perception.LIGHT_TAG. Tag the lights that matter to the AI (a flashlight, the ceiling lamps, a fire) and pass this as a Sight Visibility, and a player in the dark is invisible until a light finds them. Not physically accurate; a gameplay number.

SeenByAnyone​

</>
Perception.SeenByAnyone(
position: Vector3,
options: SeenByOptions?
) → boolean--

true when any observer has position inside their view cone with a clear line to it.

Types

​

interface SeenByOptions {
FieldOfView: number?--

The full angle of each observer's view cone. Default 100.

Range: number?--

Studs. Default math.huge.

Eye: ((root: BasePart) → CFrame?)?--

Where an observer looks from. Default: the character's head, else its root (Perception.EyeOf). A game that replicates the camera returns it here.

Ignore: {Instance}?--

What the sight ray passes through. Default nothing.

Observers: {BasePart}?--

Who may be looking. Default Perception.AllAliveRoots, hidden players included.

}

"Would anyone see it happen here?" The check to run before a stalker teleports, spawns or vanishes, so it only ever does so off screen. The Watched sense is the same question asked about the agent every tick; this is the one-off version about any point.

InCone​

</>
Perception.InCone(
origin: CFrame,--

The eye; its LookVector is the centre of the cone.

position: Vector3,
fieldOfViewDegrees: number,--

The full angle of the cone.

range: number--

Studs.

) → (
boolean,--

Inside the cone and within range.

number--

The dot product between the look vector and the direction to position: 1 dead ahead, 0 beside, -1 behind.

)

Is position inside the cone that opens fieldOfViewDegrees wide around origin.LookVector, within range studs? The angle is the true angle in three dimensions, so something high above is outside just as something off to the side is. A position at the origin counts as inside. The dot is returned either way, so a consideration can score on it.
