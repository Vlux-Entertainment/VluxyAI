Locomotion

Idle, walk and run for a rig, blended from its real speed through the NPCAnimator, plus one-shots by name. On the server attach it to an agent after Build(); on the client attach it to a puppet Replica. It goes when its owner does. 

VluxyAI.Locomotion.Attach(agent)
-- in a state:
VluxyAI.Locomotion.Play(agent, "Attack")

-- client, a puppet replica:
VluxyAI.Locomotion.AttachReplica(replica, {
	Animations = { Idle = idle, Walk = walk, Run = run },
	WalkSpeed = 10,
	RunSpeed = 22,
})

Types​

LocomotionOptions​

</>
interface LocomotionOptions {
Animations: {[string]: AnimationInfo}?--

Tracks to load. Must include weighted Idle and Walk; a weighted Run is blended in above WalkSpeed. Default: Roblox's R15 idle, walk, and a one-shot Attack swing.

WalkSpeed: number?--

Studs per second the walk cycle is authored for. Default 16.

RunSpeed: number?--

Studs per second the run cycle is authored for; between WalkSpeed and this the walk crossfades into the run. Only used with a Run. Default 24.

MovingThreshold: number?--

Studs per second below which the rig idles. Default 0.5.

Fade: number?--

Seconds to blend between tracks. Default 0.15.

SpeedSmoothing: number?--

Seconds over which the measured speed settles; 0 uses each frame's raw speed. Default 0.1.

}

Types

interface LocomotionBlend {
Idle: number--

Weight of the idle track, 0 to 1.

Walk: number--

Weight of the walk track.

Run: number--

Weight of the run track; 0 without a run.

WalkPlayback: number--

Playback speed of the walk track.

RunPlayback: number--

Playback speed of the run track.

}

The weights and playback speeds for a speed. At or below MovingThreshold it idles; up to WalkSpeed it walks; with a run, the walk crossfades into the run between WalkSpeed and RunSpeed, and above that it runs. Each track plays at speed over the speed it is authored for. Pure.

AttachReplica​

</>
Locomotion.AttachReplica(
replica: Replica,--

Its Entity must be a Model with an Animator inside.

options: LocomotionOptions?
) → NPCAnimator--

Also kept at replica.Data.Locomotion.

Locomotion for a client rig a Replica moves: the blend follows the rig's own smoothed pivot motion, so it needs neither an agent nor physics (a puppet is usually anchored). Freeze, Play and Get take the replica as they take an agent. Undone when the replica is destroyed.

Errors

TypeDescription
stringThe entity is not a Model, has no Animator, or the animations lack a weighted `Idle` or `Walk`.

Freeze​

</>
Locomotion.Freeze(
agent: Agent | Replica,
isFrozen: boolean
) → boolean--

false when nothing is attached.

Holds every animation on the rig in its current pose (true), or lets them run again (false): the statue that stops mid-step the moment it is looked at. While frozen the blend is left alone, so the pose does not drift. Calling it with the state it is already in does nothing, so a sense may call it every tick.

Play​

</>
Locomotion.Play(
agent: Agent | Replica,
name: string--

A one-shot loaded by Attach or AttachReplica.

) → boolean--

false when nothing is attached or the name is unknown.

Plays a one-shot if locomotion is attached, so a state works with or without it. An unknown name is warned about once per owner and returns false; a weighted name is an error, as it is on the animator.
