Surroundings

A Types.Sense that casts a ring of rays and writes the nearest obstacle and the most open direction. Distances are math.huge when there is nothing to measure.

Types​

SurroundingsOptions​

</>
interface SurroundingsOptions {
Rays: number?--

Rays around the agent, evenly spaced. Default 8.

Distance: number?--

Reach of each ray in studs. Default 12.

Height: number?--

Added to the agent's root position for the cast origin. Default 0.

Ignore: ((agent: Agent) → {Instance})?--

Instances the rays pass through, on top of the agent's own entity, which always is.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
