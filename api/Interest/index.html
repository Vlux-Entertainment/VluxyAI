Interest

A shared map of points of interest with a strength each, and Best, which picks where an agent should look next. Exposed as VluxyAI.Interest. Make one per map, fill it from your level (hiding spots, doors, rooms, the generator), raise points from events, and give enemies a States.Roam over it or ask Best from a state of your own. 

local interest = VluxyAI.Interest.new({ Decay = 0.1, Visited = 30 })
for _, locker in CollectionService:GetTagged("Locker") do
	interest:Add(locker, { Position = locker.Position, Strength = 1, Tags = { "Hiding" } })
end
noises:Connect(function(position, loudness)
	interest:BumpNear(position, 15, loudness or 1) -- a noise makes nearby spots worth a look
end)

Search = VluxyAI.States.Roam({ Interest = interest, Then = "Patrol", Duration = 40 }),

An enemy never learns where a player is from this; it learns where a player would plausibly be. Pair it with Sight's PredictedPosition for "they went that way" and the enemy hunts like something that has to look.

Types

​

interface BestOptions {
Range: number?--

Studs at which distance alone scores a point to nothing. Default 120.

Tags: {string}?--

Only points carrying one of these tags.

Exclude: {any}?--

Point ids to leave out (the one the agent is standing at, say).

Considerations: {Consideration<InterestPoint>}?--

Extra scoring, multiplied in.

}

Scores every point by strength (against the strongest) and nearness (linear to Range), multiplied, then any Considerations given, and returns the best. A point this agent visited within Visited seconds scores 0, so a roaming enemy spreads its search instead of circling one spot.
