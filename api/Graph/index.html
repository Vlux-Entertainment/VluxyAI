Graph

A Types.Pathfinder over hand-placed nodes with A*. Use it for the long legs of a level a navmesh cannot plan across (doors, one-way drops), and compose it with a local pathfinder through Hybrid. Name is "Graph". 

local graph = VluxyAI.Pathfinders.Graph.FromInstances(workspace.NavGraph)
local pathfinder = VluxyAI.Pathfinders.Hybrid.new({
	Graph = graph,
	Local = VluxyAI.Pathfinders.Navmesh.new(),
})

interface GraphBuildOptions {
LinkRadius: number?--

Studs within which two nodes are linked automatically when the link test passes. Default 24.

AutoLink: boolean?--

Turn the automatic linking off to use only explicit links. Default true.

Ignore: {Instance}?--

Instances the linking rays pass through (the node parts themselves always are).

CanLink: ((
a: Vector3,
b: Vector3
) → boolean)?--

Replaces the ray test: return true when an agent can walk from a to b. Ask your navmesh here for anything but flat floors.

Graph: GraphOptions?--

Options for the graph itself (NearestLimit, LineOfSight).

}

Reads a graph out of the place. Every BasePart or Attachment directly under container is a node at its position (a part's position is lowered to its bottom face, rotation taken into account). An ObjectValue named Link under a node whose value is another node is a one-way link; add the reverse for two-way; a value outside the container is warned about and skipped. A Link with an Action or Label attribute, or an ObjectValue child named Instance, becomes a [Graph.GraphLink]: set Label = "Door" and point Instance at the door, and the step at that node carries both. With AutoLink, nodes within LinkRadius of each other are linked both ways when CanLink says so, or, without it, when a ray 1.5 studs up between them is clear. The ray test is a line-of-sight test, not a walkability test: it links across a pit and refuses a staircase, so on anything but flat floors give CanLink a real answer.

Errors

TypeDescription
stringNo nodes under the container.

Close​

</>
Graph.Close(
self: GraphClass,
step: Step,--

The step a handler refused: its Instance, Label and Position find the link.

seconds: number--

How long to plan around it.

) → ()

Closes every link that emitted this step (same Instance when the step has one, else the same Label leaving the node at the step's position) for seconds, so the next plan goes another way. The Navigator calls this when a step handler returns false; a game may call it when a door locks.
