Builder

Stacks the parts of an AI and builds an Agent from them.

local agent = VluxyAI.new(model)
	:UseBrain(Stalker)
	:UsePathfinder(VluxyAI.Pathfinders.Navmesh.new({ AgentRadius = 2 }))
	:UseMover(VluxyAI.Movers.Humanoid.new(model))
	:AddSense(VluxyAI.Senses.Sight.new({ Range = 40 }))
	:Build()
	:Start()

Every method returns the builder. Builder:Build validates the definition and errors with the path of the first bad field. A builder makes one agent; call VluxyAI.new again for the next.

Types

​

interface OnStepOptions {
Tag: string?--

Find the door for a step that has no Instance: the nearest instance with this CollectionService tag within Radius of the step. Default none.

Radius: number?--

Studs. Default 8.

}

What the agent does at a labelled step. The navigator holds the mover there, reports Interacting, runs the handler in its own thread, and walks on when it returns. A graph link brings its Instance along; a navmesh PathfindingLink or modifier does not, so give Tag and the nearest tagged instance is looked up for it, and the handler is the same for both. 

:OnStep("Door", function(agent, step)
	if step.Instance:GetAttribute("Locked") then
		return false, 15 -- go another way for a while
	end
	Doors.Open(step.Instance)
	task.wait(0.4)
	return true
end, { Tag = "AI_DOOR" })
