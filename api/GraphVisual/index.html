GraphVisual

Debug view of a [Graph]: a ball per node and a bar per link, purple and see-through by default. Pass the graph itself or its node list. 

local graph = VluxyAI.Pathfinders.Graph.new(nodes)
VluxyAI.Debug.GraphVisual.new(graph)

The undirected edges of a directed node list: a link from 3 to 7 and one from 7 to 3 are one edge. A label on either direction is kept. Pure.

Types

interface GraphVisualOptions {
Color: Color3?--

Colour of the nodes and links. Default purple.

Transparency: number?--

Default 0.5.

NodeSize: number?--

Diameter of a node ball in studs. Default 1.2.

LinkThickness: number?--

Width of a link bar in studs. Default 0.2.

Nodes: boolean?--

Draw the nodes. Turn it off when the nodes are visible parts already. Default true.

Links: boolean?--

Draw the links. Default true.

Height: number?--

Studs above each node's floor position to draw at. Default 0.6.

}

Draws the graph once. The nodes of a Graph do not move, so there is nothing to redraw; destroy it and make another after changing the node list.
