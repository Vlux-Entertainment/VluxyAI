NPCAnimator

Plays and blends animations on an NPC rig by name.

local animator = VluxyAI.Animator.new(model, {
	Idle = { Id = 123, Weighted = true },
	Walk = { Id = 456, Weighted = true },
	Swing = { Id = 789, Weighted = false },
}):Load()

animator:SetWeight("Walk", 1)
animator:Play("Swing")

Load every animation up front in Load; adding tracks later is not supported.

AnimationInfo​

</>
interface AnimationInfo {
Id: number--

The animation asset id.

Weighted: boolean--

true for a looped, always-playing track blended by weight; false for a one-shot.

Priority: Enum.AnimationPriority?--

Default Enum.AnimationPriority.Movement for weighted, Action for one-shots.

Speed: number?--

Playback speed. Default 1.

}

One animation in the table given to NPCAnimator.new.
