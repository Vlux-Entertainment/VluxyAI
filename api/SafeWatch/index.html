SafeWatch

A Types.Sense for players in SafeAreas. Writes SafeTarget, SafePosition and SafeDistance for the nearest player it can see standing in an enabled safe area, so a brain can stop and stare (States.Stare) rather than try the door. With Evict (the default) it also moves its own agent out of a safe area that was switched on around it. 

:AddSense(VluxyAI.Senses.SafeWatch.new({ Spots = graph }))

Types​

SafeWatchOptions​

</>
interface SafeWatchOptions {
Range: number?--

Studs within which a player in a safe area is noticed, with a clear line to them. Default 60.

EyeOffset: Vector3?--

Added to the entity's pivot to get the eye. Default Vector3.zero.

Evict: boolean?--

Move the agent out when it finds itself in an enabled safe area. Default true.

Spots: ({Vector3} | {GetNodes: (self: any) → {{Position: Vector3}}})?--

Where an evicted agent may go: floor positions, or a Graph whose nodes are used. The nearest one outside every safe area is chosen. Without it the agent is pushed out through the nearest face of the area's box.

Height: number?--

Studs above a spot's floor to put the body. Default 3, a humanoid's root.

Remember: number?--

Seconds a player stays "the one being chased" after Sight last wrote them as SeenTarget. Such a player in a safe area counts even with no line to them. Default 10.

Forget: boolean?--

When the player in the safe area is one being chased, Sight.Forget the sighting, so the chase has nothing left to follow. Default true.

SightPrefix: string?--

The Prefix of the Sight whose keys are read and forgotten. Default "".

Prefix: string?--

Prepended to every key this sense writes. Default "".

}
