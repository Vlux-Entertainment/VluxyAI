Kill

Kills a character from an agent in one of two ways, decided and finished on the server, and announced as a "Kill" event on Agent.Events with { Kind, Victim, Duration } so a client Replica can present it: replica:On("Kill", ...).

  • [Kill.Live]: the victim is held next to the killer while both play an animation, then dies.
  • [Kill.BlackBox]: announced at once, resolved after a delay; the client cuts to black.
  • [Kill.Scare]: the live hold without the death, announced as "Scare"; the victim is let go.

A kill that was announced and then cancelled (or lost to another cause of death) emits "KillCancelled" with { Kind, Victim }, so the client can put its screen back; a scare cut short emits "ScareCancelled".

Types

interface LiveKillOptions {
Duration: number?--

Seconds the hold lasts before the victim dies. Default 1.5.

Offset: CFrame?--

Where the victim is held, relative to the killer's pivot. Default 2.5 studs in front, facing the killer.

KillerAnimation: number | string?--

Played on the killer: an animation asset id, or the name of a one-shot on the killer's Locomotion. Default none.

VictimAnimation: number?--

Animation asset id played on the victim. Default none.

Health: HealthProvider?--

Where the victim's health lives, when not on the Humanoid.

}

Emits Kill with Kind = "Live", anchors the victim's root, holds it at Offset from the killer every frame, plays the animations, and after Duration sets the victim's health to zero (bypassing a ForceField, as a kill should). Cancel releases the victim alive.

Finishes false at once, with a warning, when the victim has no humanoid or root, is dead, or is already held by another live kill, or when the agent is not running. Finishes false if the killer is destroyed or the victim dies of something else during the hold.

Types

​

interface ScareOptions {
Duration: number?--

Seconds the hold lasts before the victim is let go. Default 1.

Offset: CFrame?--

Where the victim is held, relative to the killer's pivot. Default 2.5 studs in front, facing the killer.

Damage: number?--

Dealt when the hold ends. Default 0.

KillerAnimation: number | string?--

Played on the killer: an asset id, or a Locomotion one-shot name. Default none.

VictimAnimation: number?--

Animation asset id played on the victim. Default none.

Health: HealthProvider?--

Where the victim's health lives, when not on the Humanoid.

}

The live hold without the death: emits Scare with Kind = "Scare", holds the victim at Offset while both animations play, deals Damage when the time is up, and releases them. A jump scare, a grab that throws the player off, a bite that does not finish them. The same refusals as Kill.Live; a victim already held by a kill or another scare is refused.
