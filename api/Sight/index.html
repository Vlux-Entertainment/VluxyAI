Sight

A Types.Sense that writes what the agent can see. A target is seen when it is within Range, inside the FieldOfView cone around the entity's look direction, and a ray from the eye to it hits nothing but the target's own model.

Writes SeenTargets, SeenTarget, SeenDistance, SeenVisibility, SeenPosition and SeenAt. The last two are memory: they outlive the sighting by Memory seconds so a state can head to where the target was. Distances are math.huge when there is nothing to measure.

For a horror game: Visibility scales the range per target, so darkness and a lit flashlight are one function (Perception.LightAt is the ready-made one); SeeThrough lets the ray pass glass (Perception.Transparent); and a player hidden with AI_HIDDEN is not a target at all.

Types​

SightOptions​

</>
interface SightOptions {
Range: number?--

Studs the agent can see. Default 40.

FieldOfView: number?--

The full angle of the view cone, in degrees. Default 120.

EyeOffset: Vector3?--

Added to the entity's pivot to get the eye. Default Vector3.zero.

Memory: number?--

Seconds SeenPosition and SeenAt outlive the last sighting. Default 3.

Targets: ((agent: Agent) → {BasePart})?--

What to look for. Default Perception.AliveRoots, every alive player's root.

Ignore: ((agent: Agent) → {Instance})?--

What the sight ray passes through. Default Perception.IgnoreList, the agent's entity.

Visibility: ((
agent: Agent,
target: BasePart
) → number)?--

How visible a target is, 0 to 1 (or more): the range is multiplied by it, so 0 is invisible and 0.5 is seen at half the distance. Pass function(_, root) return VluxyAI.Perception.LightAt(root.Position) end for darkness. Default: everything 1.

SeeThrough: ((part: BasePart) → boolean)?--

Parts the sight ray looks past, such as Perception.Transparent. Default: everything blocks.

PerTarget: boolean?--

Also write SeenMemory, the last position and time of every target seen within Memory seconds, so an enemy remembers where each of several players went. Default false.

Predict: number?--

Seconds of the target's last velocity to carry PredictedPosition forward after losing sight, capped. 0 turns prediction off. Default 2.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
