Throttle

Wraps a Types.Sense so it ticks every interval seconds instead of every agent tick. The first tick runs at once. Exposed as VluxyAI.Senses.Throttle. 

:AddSense(VluxyAI.Senses.Throttle.new(VluxyAI.Senses.Sight.new({ Range = 40 }), 0.3))

The wrapped sense's blackboard keys keep their last values between runs, so a memory such as SeenPosition still ages by the wrapped sense's own clock.
