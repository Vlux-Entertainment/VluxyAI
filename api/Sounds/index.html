Sounds

A Types.Sense that hears the Sound instances in the world. Tag a sound with CollectionService ("AI_SOUND" by default), parent it to a part or an attachment so it is 3D, and every agent with this sense judges it each tick while it plays: the sound's Volume rolled off over the distance the way Roblox plays it, times the sound's AI_SOUND/Multiplier attribute when it has one. The loudest sound still above Threshold is written as HeardSound with its position, distance, loudness at the agent and the time, and the memory keys stay for Memory seconds after it stops so a state can go and look. Exposed as VluxyAI.Senses.Sounds. The tag and the attribute name are prefixed so they do not collide with a game's own; both are options. 

-- the game, once per sound worth noticing
CollectionService:AddTag(radio.Sound, "AI_SOUND")
radio.Sound:SetAttribute("AI_SOUND/Multiplier", 2) -- twice as far as its roll-off alone

-- the agent
:AddSense(VluxyAI.Senses.Sounds.new({ Threshold = 0.1, Memory = 8 }))

-- a transition in the brain
{ To = "Investigate", When = function(agent)
	return agent.Blackboard.HeardSoundAt ~= nil and agent.Blackboard.HeardSoundAt ~= agent.Data.InvestigatedAt
end }

A sound with no tag, one that is not playing, one parented to a folder or to SoundService (so it is 2D), one with Volume 0 and one the agent itself carries are never heard. The one signal-based sense, Hearing, is for events your code fires; this one is for sounds the world is already playing. One instance may serve many agents: it keeps no per-agent state.

Types​

SoundsOptions​

</>
interface SoundsOptions {
Tag: string?--

The CollectionService tag a Sound must carry to be heard. Default "AI_SOUND".

Threshold: number?--

The volume a sound must still have at the agent, after roll-off and the attribute, to be heard. Default 0.05.

MultiplierAttribute: string?--

A number attribute on the Sound that multiplies its volume for the AI: 2 carries twice as loud, 0.5 half, 0 is never heard. Missing means 1. Default "AI_SOUND/Multiplier".

Memory: number?--

Seconds the memory keys outlive the last audible tick. Default 5.

Occlusion: number?--

Volume multiplier per wall between the sound and the agent, 0 to 1. 1 (the default) casts no rays; 0.5 halves a sound per wall.

OcclusionWalls: number?--

Walls counted at most. Default 3.

Filter: ((
sound: Sound,
agent: Agent
) → boolean)?--

Return false to ignore a sound for this agent. The agent's own sounds (under its entity) are ignored without it.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}

Attenuate​

</>
Sounds.Attenuate(
distance: number,--

Studs from the sound to the listener.

volume: number,--

The sound's Volume.

minDistance: number,--

RollOffMinDistance: full volume up to here.

maxDistance: number,--

RollOffMaxDistance: silence (linear modes) or no further attenuation (inverse) from here.

mode: string--

The RollOffMode name: Inverse, InverseTapered, Linear or LinearSquare. Anything else is Inverse.

) → number--

The volume at the listener, in [0, volume].

The roll-off curves as Roblox plays them, pure. Within minDistance a sound is at full volume. Inverse falls as minDistance / distance and stops falling at maxDistance; Linear and LinearSquare fall to nothing at maxDistance, the second along a squared curve; InverseTapered is the quieter of Inverse and LinearSquare, so it follows the inverse curve up close and still reaches silence at maxDistance.
