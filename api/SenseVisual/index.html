SenseVisual

Debug view of an agent's perception: the sight cone, the hearing and proximity circles, and markers at SeenPosition, PredictedPosition and LastKnownPosition. Exposed as VluxyAI.Debug.SenseVisual. Make one after building the agent, hand it the senses (or their numbers), and destroy it with the agent. 

local sight = VluxyAI.Senses.Sight.new({ Range = 40, FieldOfView = 120 })
local agent = VluxyAI.new(rig):UseBrain(Brain):AddSense(sight):Build()
local view = VluxyAI.Debug.SenseVisual.new(agent, { Sight = sight, Hearing = 30 })
agent.Destroyed:Connect(function() view:Destroy() end)
