Hybrid

A Types.Pathfinder that composes a Graph for the level and a local pathfinder for the geometry, the way the design plan lays it out. Name is "Hybrid". Blocked is the local pathfinder's Blocked when it has one, so a blocked local leg re-plans the whole route.

interface HybridOptions {
Graph: Pathfinder--

The long-range pathfinder, usually a Graph.

Local: Pathfinder--

The short-range one, usually a Navmesh or a Ladder of Straight and Navmesh.

LocalRadius: number?--

Studs within which the local pathfinder is tried first. Default 40.

RefineEnds: boolean?--

Plan the first and last legs locally. Default true.

}
