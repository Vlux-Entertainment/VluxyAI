When

Builders for the When of a Types.Transition or a Types.Interrupt. Exposed as VluxyAI.When. 

local When = VluxyAI.When

Interrupts = {
	{ To = "Hunt", When = When.Has("SeenTarget"), Except = { "Hunt", "Attack" } },
	{ To = "Investigate", When = When.New("HeardAt"), Except = { "Hunt", "Attack" } },
},
States = {
	Hunt = { Transitions = {
		{ To = "Attack", When = When.Below("SeenDistance", 4) },
		{ To = "Search", When = When.Missing("SeenPosition") },
	} },
	Search = { Transitions = { { To = "Patrol", When = When.Timer("Search") } } },
}

New​

</>
When.New(
key: string--

A memory key that changes with each new event: HeardAt, HeardSoundAt, LastKnownAt.

) → (agent: Agent) → boolean--

true once per distinct value.

"Something new is here." Reads Agent:IsNew and, when it is true, calls Agent:Acknowledge before returning, so the same noise fires one transition and not one per tick. A state may acknowledge earlier itself, and a state that wants to react again to the same value may clear the key.
