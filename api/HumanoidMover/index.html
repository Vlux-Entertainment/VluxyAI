HumanoidMover

A Types.Mover for a model with a Humanoid and a PrimaryPart: walks each step with MoveTo, jumps at Jump steps, and gives up when the rig stops making progress for StuckTimeout seconds. Exposed as VluxyAI.Movers.Humanoid.

Roblox fires MoveToFinished(false) eight seconds after any MoveTo, reached or not, so a step further than eight seconds of walking would otherwise end a healthy walk. The mover re-issues the MoveTo for the same step while the stuck check sees progress and only gives up when the stuck check agrees.

Follows the two mover rules: Follow fires Arrived(false) for the path it replaces before starting the new one, and the new path is only ever reported from a later frame, because MoveToFinished never fires inside MoveTo.

Skips the run of leading plain Walk steps that sit within skipDistance of position, because a navmesh path starts where the agent already stands. A labelled, Jump or Custom step is never skipped, even one under the agent: it carries meaning (a door at the agent's feet) that StepReached must report. The last step is never skipped either, so there is always something to walk toward and arrival is always reported from MoveToFinished.

Types

interface HumanoidOptions {
Speed: number?--

WalkSpeed, studs per second. Default 16.

StuckTimeout: number?--

Seconds without moving StuckDistance before giving up. Default 3.

StuckDistance: number?--

Studs the root must move within StuckTimeout to count as progress. Default 0.5.

SkipDistance: number?--

Leading plain Walk steps within this horizontal distance of the rig are skipped. Default 1.

ServerOwned: boolean?--

Set the root's network owner to the server in new. Default true.

Noise: MoverNoise?--

Fire a Hearing noise signal every Interval seconds while walking, so other agents hear this one coming. Off by default.

}

Sets WalkSpeed to Speed and, with ServerOwned, hands the root to the server. That fails, with a warning, unless the model is a descendant of Workspace and unanchored before this call.

position: Vector3?--

Where to face; nil to stop.

Turns the root toward position every Heartbeat while no path is in progress, so a rig can stare at a player without walking. MoveTo steers while walking, so a path takes over and the facing resumes when it ends. Sets the root's CFrame, which is what a server-owned rig standing still expects.
