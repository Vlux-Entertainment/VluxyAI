Awareness

A Types.Sense that turns sightings and noises into a detection meter, the way a stealth game does it: a player who steps into view is not hunted at once but makes the enemy suspicious, then alerted if they stay; a noise nudges the meter; silence drains it. Exposed as VluxyAI.Senses.Awareness. Add it after Sight, Hearing and Sounds, since it reads what they wrote. 

:AddSense(VluxyAI.Senses.Sight.new({ Range = 40 }))
:AddSense(VluxyAI.Senses.Hearing.new(noises))
:AddSense(VluxyAI.Senses.Awareness.new({ Rise = 0.8, Fall = 0.2 }))

Interrupts = {
	{ To = "Hunt", When = When.Equals("AwarenessLevel", "Alerted"), Except = { "Hunt", "Attack" } },
	{ To = "Investigate", When = When.Equals("AwarenessLevel", "Suspicious"), Except = { "Hunt", "Attack", "Investigate" } },
},
Investigate = States.Investigate({ Target = "LastKnownPosition", Then = "Patrol" }),

AwarenessSource​

interface AwarenessSource {
Name: string--

Written to LastKnownSource when this source is the latest.

While: string?--

A blackboard key that is non-nil every tick the stimulus is present, such as SeenTarget. The meter rises at Rise * Weight per second.

At: string?--

A blackboard key holding a timestamp that changes per event, such as HeardAt. The meter jumps by Weight once per new value.

Position: string?--

The blackboard key holding where it is, copied to LastKnownPosition.

Weight: number?--

Default 1.

}

AwarenessOptions​

</>
interface AwarenessOptions {
Rise: number | (agent: Agent) → number?--

How much the meter rises per second per unit of While weight, or a function of the agent (closer means faster, say). Default 1.

Fall: number?--

How much it drains per second when no source is present. Default 0.25.

Suspicious: number?--

The level at which AwarenessLevel becomes "Suspicious". Default 0.3.

Alerted: number?--

The level at which it becomes "Alerted". Default 1.

Sources: {AwarenessSource}?--

What feeds the meter. Default: SeenTarget at weight 1, HeardAt at 0.5, HeardSoundAt at 0.3.

Key: string?--

The agent.Data key for the counted timestamps. Default "Awareness".

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
