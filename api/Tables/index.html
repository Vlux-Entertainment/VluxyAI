Tables

Small table helpers the package shares: deep copy, sorted keys, a flat distance and a prefixed view. Exposed as VluxyAI.Tables.

Functions​

Prefixed​

</>
Tables.Prefixed(
target: {[string]: any},
prefix: string
) → {[string]: any}--

target itself when prefix is empty, else a view whose reads and writes go to prefix .. key.

A prefixed view of a table, so a sense given Prefix = "Peripheral" writes PeripheralSeenTarget without knowing. Costs one small table per call; nothing at all when the prefix is empty, which is the default everywhere.
