Watched

A Types.Sense that writes who is looking at the agent. An observer sees the agent when the agent's pivot is inside the observer's FieldOfView cone within Range, and (unless RequireLineOfSight is off) a ray from the observer's eye to the pivot reaches the agent's entity. Writes WatchedBy, IsWatched, WatchedAt and UnwatchedFor, which is what a freeze-when-seen state reads. UnwatchedFor is math.huge until the first time it is watched.

By default an observer's eye is its character's head, so "looking" means the head's facing, which on a default rig is the walk direction rather than the camera. A game that wants the real camera direction replicates it to the server and passes Eye.

Types​

WatchedOptions​

</>
interface WatchedOptions {
Range: number?--

Studs from which an observer can see the agent. Default 60.

FieldOfView: number?--

The full angle of the observer's view cone, in degrees. Default 90.

RequireLineOfSight: boolean?--

Cast a ray from the observer to the agent, or trust the cone alone. Default true.

Targets: ((agent: Agent) → {BasePart})?--

Who might be looking. Default Perception.AliveRoots, every alive player's root.

Ignore: ((agent: Agent) → {Instance})?--

Extra instances the observer's ray passes through, on top of the observer's own character. Default none.

Eye: ((root: BasePart) → CFrame?)?--

Where an observer looks from and which way: a replicated camera, say. nil falls back to the default. Default the head's CFrame when the character has one, else the root's.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
