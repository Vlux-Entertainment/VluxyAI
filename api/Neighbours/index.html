Neighbours

A Types.Sense for enemies that share a map: who else from the group is near, which way is away from them, and, when asked, an eased speed and a sideways nudge so they do not pile up. One instance is one group; make it once and add it to every enemy that should know about the others. Exposed as VluxyAI.Senses.Neighbours. 

local crowd = VluxyAI.Senses.Neighbours.new({
	Range = 10,
	Slow = { Distance = 5, Min = 0.5 },  -- half speed when shoulder to shoulder
	Avoid = { Radius = 4 },              -- step aside within four studs
})
-- every enemy in the group
:AddSense(crowd)

Enemies that should crowd (a swarm) take the sense without Slow and Avoid, or with Distance = 0 and Radius = 0, or leave it out. One enemy in a shared group opts out for itself with agent.Data.Neighbours = { Slow = false } or { Avoid = false } (the Key option renames it). An enemy that must ignore one kind gives Filter; Configure turns either behaviour on or off for the whole group later.

NeighboursSlow​

interface NeighboursSlow {
Distance: number--

Studs from the nearest neighbour at which the ease begins. Further away the speed is untouched. 0 turns the ease off.

Min: number?--

The speed scale when the neighbour is on top of the agent. Default 0.5.

Curve: Curve?--

Shape of the ease over [0, 1] (distance over Distance). Default linear.

}

NeighboursAvoid​

</>
interface NeighboursAvoid {
Radius: number--

Studs within which a neighbour pushes the agent sideways. 0 turns the nudge off.

Strength: number?--

How hard: the nudge is up to Strength * Radius studs. Default 1.

Deadband: number?--

Studs the nudge must change by before the mover is told again, against jitter when neighbours keep moving. Default 0.

}

NeighboursOptions​

</>
interface NeighboursOptions {
Range: number?--

Studs within which another agent counts as nearby. Default 10.

Slow: NeighboursSlow?--

Ease the agent's speed as its nearest neighbour gets close. Off by default, and off with Distance = 0.

Avoid: NeighboursAvoid?--

Nudge the mover away from neighbours while walking. Off by default, off with Radius = 0; needs a mover with SetNudge (both built-ins have it).

Others: ((agent: Agent) → {Agent})?--

Who counts, instead of the agents sharing this instance.

Filter: ((
agent: Agent,
other: Agent
) → boolean)?--

Return false to ignore other for agent: same kind only, say.

Prefix: string?--

Prepended to every key this sense writes. Default "".

Key: string?--

The agent.Data key an enemy may set to opt out for itself: agent.Data.Neighbours = { Slow = false, Avoid = false }. Default "Neighbours".

}
