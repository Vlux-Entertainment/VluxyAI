Proximity

A Types.Sense that writes who is within Range of the agent, nearest first, with no regard for sight. Writes NearbyTargets, NearestTarget and NearestDistance. Distances are math.huge when there is nothing to measure.

Types​

ProximityOptions​

</>
interface ProximityOptions {
Range: number?--

Studs within which a target counts as nearby. Default 100.

Targets: ((agent: Agent) → {BasePart})?--

What to measure. Default Perception.AliveRoots, every alive player's root.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
