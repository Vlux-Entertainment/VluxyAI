CFrameMover

A Types.Mover that steps a pivot with PivotTo, for anchored parts, rigless models and agents that only exist as a position on the server. Exposed as VluxyAI.Movers.CFrame. Each Heartbeat it moves toward the current step at Speed and turns its yaw toward the direction of travel at TurnSpeed; pitch and roll are dropped, so the pivot stays upright.

Follows the two mover rules: Follow fires Arrived(false) for the path it replaces before starting the new one, and the new path is only ever reported from a later Heartbeat.

interface CFrameMoverOptions {
Speed: number?--

Studs per second. Default 8.

TurnSpeed: number?--

Radians per second of yaw. Default 10.

HeightOffset: number?--

Added to every step's Y, so a body rides above floor steps. A number is used as given; leave it out and the first Follow measures the pivot's height above the first step (never below 0) and keeps that for the life of the mover. Default: measured.

StepDistance: number?--

Horizontal distance to a step that counts as reached. Default 0.25.

StuckTimeout: number?--

Seconds without getting closer to the current step before giving up with Arrived(false). Default 5. Progress under 0.05 studs per check does not count, so speeds below about 0.01 studs per second read as stuck.

Noise: MoverNoise?--

Fire a Hearing noise signal every Interval seconds while walking, so other agents hear this one coming. Off by default.

}

Follow​

</>
CFrameMover.Follow(
self: CFrameMover,
path: Path
) → ()

Starts along path, replacing any current one. The replaced path gets Arrived(false) before the new one starts; the new one is only ever reported from a later Heartbeat. An empty path is reported as Arrived(false) on the next Heartbeat.

Without a HeightOffset option, the first non-empty path measures it: the pivot's height above path[1], never below 0, kept from then on.
