VluxyAI

Simple, composable AI for Roblox. An AI is a brain (a table of states), a pathfinder (plans), a mover (executes) and some senses (write a blackboard), stacked with the builder into an agent. 

local VluxyAI = require(ReplicatedStorage.Packages.VluxyAI)

local agent = VluxyAI.new(model)
	:UseBrain(Stalker)
	:UsePathfinder(VluxyAI.Pathfinders.Navmesh.new({ AgentRadius = 2 }))
	:UseMover(VluxyAI.Movers.Humanoid.new(model))
	:AddSense(VluxyAI.Senses.Sight.new({ Range = 40 }))
	:Build()
	:Start()

Every part is a contract in Types; pass your own module in to extend the package.

The built-in Types.Pathfinders: Navmesh for geometry, Straight for a clear line, Ladder to try several in order, Graph for A* over authored nodes, and Hybrid to compose a graph with a local pathfinder.

Senses​

</>
VluxyAI.Senses: {
Sight: Sight,
Proximity: Proximity,
Hearing: Hearing,
Sounds: Sounds,
Awareness: Awareness,
Watched: Watched,
Surroundings: Surroundings,
Neighbours: Neighbours,
Throttle: Throttle
}

The built-in Types.Senses. Hearing is for noises your code fires; Sounds is for the tagged Sound instances the world is already playing; Awareness turns what the others wrote into a detection meter; Neighbours is the group sense, so enemies sharing a map know about each other and, when asked, keep out of each other's way.

Director​

</>
VluxyAI.Director: Director

Pacing and shared knowledge for a group of enemies: a tension meter, a difficulty knob and a shared blackboard, read through director:Sense().

Interest​

</>
VluxyAI.Interest: Interest

Points of interest with a strength each, and Best to pick where an enemy looks next. States.Roam walks one.

Claims​

</>
VluxyAI.Claims: Claims

A shared "who is on what" table, so two enemies never chase the same player unless you say so.

Tables​

</>
VluxyAI.Tables: Tables

The package's small table helpers, including Tables.Prefixed.

Perception​

</>
VluxyAI.Perception: Perception

The helpers the built-in senses are made of: alive player roots, cones, line of sight, and HumanoidOf for a state that acts on a target. The place to start for a custom sense.

Sync​

</>

Client-side presentation: a Broadcaster watches an agent on the server, a Replica drives a rig and your client states on the client. The game owns the remotes between them.

Internals​

</>

}

The pieces the Agent is made of, for a custom scheduler or a client renderer that wants to run a brain table itself.

Presets​

</>
VluxyAI.Presets: {Humanoid: (
model: Model,
options: HumanoidPresetOptions?
) → Builder}

Ready-made stacks. Presets.Humanoid(model) returns a Builder already carrying a Ladder of Straight then Navmesh (a target in plain sight costs no navmesh query), a HumanoidMover mover, Sight and Proximity senses, and a quarter-second repath; add a brain and build. It is what the examples build by hand, opt-in and overridable.
