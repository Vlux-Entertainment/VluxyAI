VluxyAI

Simple, composable AI for Roblox. An AI is a brain (a table of states), a pathfinder (plans), a mover (executes) and some senses (write a blackboard), stacked with the builder into an agent. 

local VluxyAI = require(ReplicatedStorage.Packages.VluxyAI)

local agent = VluxyAI.new(model)
	:UseBrain(Stalker)
	:UsePathfinder(VluxyAI.Pathfinders.Navmesh.new({ AgentRadius = 2 }))
	:UseMover(VluxyAI.Movers.Humanoid.new(model))
	:AddSense(VluxyAI.Senses.Sight.new({ Range = 40 }))
	:Build()
	:Start()

Every part is a contract in Types; pass your own module in to extend the package.

Types​

HumanoidPresetOptions​

</>
interface HumanoidPresetOptions {
Navmesh: NavmeshOptions?--

Options for Navmesh.new.

Straight: StraightOptions?--

Options for Straight.new, the direct walker.

Mover: HumanoidOptions?--

Options for HumanoidMover.new.

Sight: SightOptions?--

Options for Sight.new.

Proximity: ProximityOptions?--

Options for Proximity.new.

Navigation: NavigationOptions?--

Navigator tuning. Default { RepathInterval = 0.25, MaxPathAge = 2 }.

Graph: Pathfinder?--

Authored nodes (Graph): routes go over the graph first (Hybrid with Prefer = "Graph", RefineEnds = false) and the navmesh answers only where the graph has no way. Without it, the navmesh plans everything.

Doors: boolean?--

Walk through doors: Doors.Step with WalkThrough for "Door" steps, a Doors.Opener sense, and a direct walker that sees past unlocked doors. For doors rigs do not collide with (Collision.LetRigsThrough). Default false.

SafeWatch: boolean?--

Add SafeWatch, so the agent notices players in safe areas and is moved out of one that switches on around it (to a Graph node when given). Default true.

}

PuppetPresetOptions​

</>
interface PuppetPresetOptions {
Navmesh: NavmeshOptions?--

Options for [Navmesh.new]: AgentRadius, AgentHeight and the rest.

Mover: CFrameMoverOptions?--

Options for [CFrameMover.new]: Speed, TurnSpeed, HeightOffset. HeightOffset defaults to 0 here, so the anchor's pivot is the floor point.

Navigation: NavigationOptions?--

Navigator tuning. Default { RepathInterval = 0.25, MaxPathAge = 2 }.

}

HeadlessPresetOptions​

</>
interface HeadlessPresetOptions {
Name: string?--

Used in messages. Default "Agent".

Position: Vector3--

Where it starts: the floor point.

Yaw: number?--

Starting yaw in radians. Default 0.

Mover: CFrameMoverOptions?--

Speed, TurnSpeed and the rest, as Record.new takes them.

Pathfinder: Pathfinder?--

Default a Navmesh built from Navmesh. A Graph or Straight keeps PathfindingService out of it.

Navmesh: NavmeshOptions?--

Options for the default Navmesh. Ignored when Pathfinder is given.

Navigation: NavigationOptions?--

Navigator tuning. Default { RepathInterval = 0.25, MaxPathAge = 2 }.

}

The built-in Types.Senses. Hearing is for noises your code fires; Sounds is for the tagged Sound instances the world is already playing; Awareness turns what the others wrote into a detection meter; Neighbours is the group sense, so enemies sharing a map know about each other and, when asked, keep out of each other's way.

Pacing and shared knowledge for a group of enemies: a tension meter, a difficulty knob and a shared blackboard, read through director:Sense().

A shared "who is on what" table, so two enemies never chase the same player unless you say so.

Presets​

</>
VluxyAI.Presets: {
Humanoid: (
model: Model,
options: HumanoidPresetOptions?
) → Builder,
Puppet: (
anchor: Model | BasePart,
options: PuppetPresetOptions?
) → Builder,
Headless: (options: HeadlessPresetOptions) → Builder
}

Ready-made stacks. Presets.Humanoid(model) returns a Builder already carrying a Navmesh pathfinder (graph-first Hybrid when Graph is given) with Straight as its direct walker, a HumanoidMover mover, Sight, Proximity and SafeWatch senses, and a quarter-second repath; Doors = true adds walking through doors. Add a brain, any senses of your own, and build. It is the stack the examples build by hand, opt-in and overridable. 

local agent = VluxyAI.Presets.Humanoid(rig, { Graph = graph, Doors = true })
	:UseBrain(Brain)
	:AddSense(VluxyAI.Senses.Clues.new(interest))
	:Build()

Presets.Puppet(anchor) is the server half of puppet mode, for an enemy with no visible body on the server: a Navmesh pathfinder and a CFrameMover on the anchor (HeightOffset 0, so its pivot is the floor point) with the same repath. A Part anchor is wrapped in a Model of its own and made invisible, anchored and inert. It adds no senses; stream it with a Broadcaster once built, and draw it on the client with a puppet Replica. 

local agent = VluxyAI.Presets.Puppet(anchorPart, {
	Navmesh = { AgentRadius = 4, AgentHeight = 12 },
	Mover = { Speed = 10, TurnSpeed = 6 },
})
	:UseBrain(Brain)
	:AddSense(VluxyAI.Senses.Hearing.new(noises))
	:Build()
local broadcaster = VluxyAI.Sync.Broadcaster.new(agent, { PositionRate = 10 })

Presets.Headless(options) is the same without any Instance on the server: a Record mover holds the pivot, and the agent moves only when it is stepped. Start it with Start(true) and step it from your own scheduler, or with Start() to tick on Heartbeat as usual. 

local agent = VluxyAI.Presets.Headless({
	Name = "Goblin 12",
	Position = spawn,
	Pathfinder = VluxyAI.Pathfinders.Graph.new(nodes),
	Mover = { Speed = 10 },
})
	:UseBrain(Brain)
	:Build()
	:Start(true)
