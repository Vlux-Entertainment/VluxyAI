Hearing

A Types.Sense that listens to a noise signal. Make one with VluxyAI.Signal.new(), hand it to every agent that should hear, and fire it with (position, loudness?) whenever something makes a sound. Each tick the sense keeps the loudest noise within Range * loudness studs of the agent (the nearest on a tie) and writes HeardPosition, HeardAt and HeardLoudness, which stay for Memory seconds and then clear. One instance may serve many agents: noises are buffered per agent, and each agent's tick empties only its own buffer.

Types​

HearingOptions​

</>
interface HearingOptions {
Range: number?--

Studs a noise of loudness 1 carries. A noise is heard within Range * loudness. Default 30.

Memory: number?--

Seconds the heard keys outlive the last heard noise. Default 5.

Occlusion: number?--

Loudness multiplier per wall between the noise and the agent, 0 to 1. 1 (the default) casts no rays; 0.5 halves a noise per wall.

OcclusionWalls: number?--

Walls counted at most. Default 3.

Prefix: string?--

Prepended to every key this sense writes, so two instances can coexist. Default "".

}
