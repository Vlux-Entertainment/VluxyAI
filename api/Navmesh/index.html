Navmesh

A Types.Pathfinder over Roblox's PathfindingService. One Path instance per navmesh, created in new with the agent parameters and reused for every FindPath, so make one per agent rather than one per plan. Never share one between agents: ComputeAsync yields, so a second agent's plan would overwrite the waypoints the first is about to read.

Name is "Navmesh", which Ladder uses in its reasons. Blocked fires whenever the Path instance reports its last computed path blocked, so a Navigator re-plans when a door closes or a part moves into the way instead of waiting for the mover's stuck check.

Simplify​

</>
Navmesh.Simplify(path: Path) → Path--

A new path; the input is not modified.

Removes interior Walk steps that lie on the straight line between the last kept step and the next one, so a mover walks one long segment instead of many short collinear ones. Pure.

Always kept: the first and last step, every Jump or Custom step, every step with a Label, and the step immediately before a Jump (the jump origin matters). A path of two or fewer steps comes back as a copy.

CollapseLabels​

</>
Navmesh.CollapseLabels(path: Path) → Path--

A new path; the input is not modified.

Merges each run of consecutive steps that share a Label into the first of them, keeping its position. A PathfindingModifier labels every waypoint inside its volume, and waypoints sit a couple of studs apart, so a doorway would otherwise be two or three "Door" steps and a handler would run at each. A run is broken by an unlabelled step or a different label. Pure.

FromWaypoints​

</>
Navmesh.FromWaypoints(waypoints: {PathWaypoint}) → Path

Converts Path:GetWaypoints() output to Steps: Action is the waypoint action's name and an empty Label becomes nil. Pure; any table shaped like a waypoint works.

Close​

</>
Navmesh.Close(
self: Navmesh,
step: Step,--

The step a handler refused.

seconds: number--

How long to refuse paths through it.

) → ()

The navmesh is Roblox's, so a link cannot be closed for one agent; instead, for seconds, any path this pathfinder computes that crosses a step with the same label within a few studs (or the same Instance) is reported as no path, closed <label> at <position>. The Navigator calls this when a step handler returns false.
