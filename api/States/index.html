States

Factories for the states every enemy ends up writing: States.Patrol, States.Investigate, States.Search, States.Wander and States.Wait. Exposed as VluxyAI.States. 

local States = VluxyAI.States
local When = VluxyAI.When

local Brain: VluxyAI.Brain = {
	Initial = "Patrol",
	Interrupts = {
		{ To = "Hunt", When = When.Has("SeenTarget"), Except = { "Hunt", "Attack" } },
		{ To = "Investigate", When = When.New("HeardAt"), Except = { "Hunt", "Attack" } },
	},
	States = {
		Patrol = States.Patrol({ Points = "Nodes", Speed = 10 }),
		Investigate = States.Investigate({ Target = "HeardPosition", Speed = 14, Then = "Patrol" }),
		Hunt = { ... },
		Search = States.Search({ Around = "SeenPosition", Radius = 12, Points = 3, Duration = 14, Then = "Patrol" }),
		Attack = VluxyAI.Combat.Attack.State({ ... }),
	},
}

States.Roam walks the best point of an Interest map, marking each visited, so an enemy that has lost you checks the places you would plausibly be.

Every factory accepts Transitions (checked before the state's own logic, like any state), Enter and Exit hooks run after the built-in ones, Speed to set on entry, and Key, the agent.Data key its scratch lives under (default: the state's own name). Positions may be given as a blackboard or Data key, a Vector3, or a function of the agent. A point the navigator cannot reach is skipped on the next tick, so a search point inside a wall costs nothing but a failed plan.

interface PatrolOptions {
Points: string | {Vector3} | (agent: Agent) → {Vector3}--

The route: a Data key holding a list, the list itself, or a function. Required.

Order: "Loop" | "PingPong" | "Random"?--

Loop back to the first point, walk the list both ways, or pick any other point. Default "Loop".

Pause: number | {number}?--

Seconds to stand at each point, or a { min, max } range. Default none.

Speed: number?--

Set on entry.

Random: Random?--

For Random order and a ranged Pause. Default agent.Data.Random, else a new one.

Key: string?--

The Data key for the current index. Default "Patrol".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Walks the points in order, forever. The index survives leaving and re-entering the state, so an enemy that broke off to investigate resumes where it was. A point that cannot be reached is skipped.

interface InvestigateOptions {
Target: string | Vector3 | (agent: Agent) → Vector3?--

Where to go: a blackboard or Data key such as "HeardPosition", a position, or a function. Read once on entry. Required.

Then: string?--

The state to enter when there, when the target is missing, or when the path fails. Without it the state waits for a transition.

Linger: number | {number}?--

Seconds to stand at the spot before Then. Default 0.

Acknowledge: string?--

A blackboard key to Agent:Acknowledge on entry, such as "HeardAt", so the noise that brought the agent here does not count as new again.

Speed: number?--

Set on entry.

Random: Random?--

For a ranged Linger.

Key: string?--

Default "Investigate".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Goes to one place and, once there (or once the path fails), lingers and moves on to Then. The place is read on entry, so a newer noise re-enters the state through a transition rather than pulling the agent mid-walk.

interface SearchOptions {
Around: string | Vector3 | (agent: Agent) → Vector3?--

The centre: usually "SeenPosition" or "LastKnownPosition". Missing means the agent's own position. Read once on entry.

Radius: number?--

Studs around the centre the points are picked in. Default 12.

Points: number?--

How many points to pick. They are walked in turn and cycled until Duration runs out. Default 3.

Duration: number | {number}?--

Seconds to search before Then. Default 15.

Then: string?--

The state to enter when time is up. Without it the state searches until a transition.

Speed: number?--

Set on entry.

Random: Random?--

Picks the points. Default agent.Data.Random, else a new one.

Key: string?--

Default "Search".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Picks a few random points around a spot and walks them in turn until Duration runs out: the "where did they go" after losing sight. A point the navigator cannot reach is skipped.

interface RoamOptions {
Interest: Interest--

The map of points to roam. Required.

Range: number?--

Studs beyond which a point scores nothing for distance. Default 120.

Tags: {string}?--

Only points with one of these tags.

Linger: number | {number}?--

Seconds to stand at each point before moving on. Default 1.

Duration: number | {number}?--

Seconds to roam before Then. Without it, roams until a transition or until no point scores.

Then: string?--

The state to enter when time is up or no point is worth a look.

Considerations: {Consideration<InterestPoint>}?--

Extra scoring for Interest.Best.

Speed: number?--

Set on entry.

Random: Random?--

For ranged Linger and Duration.

Key: string?--

Default "Roam".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Asks the Interest map for the best point, walks there, lingers, marks it visited, and asks again. Points the agent just visited score nothing, so it spreads its search. When no point scores, or Duration runs out, it enters Then.
