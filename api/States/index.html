States

Factories for the states every enemy ends up writing: States.Patrol, States.Investigate, States.Search, States.Wander and States.Wait. Exposed as VluxyAI.States. 

local States = VluxyAI.States
local When = VluxyAI.When

local Brain: VluxyAI.Brain = {
	Initial = "Patrol",
	Interrupts = {
		{ To = "Hunt", When = When.Has("SeenTarget"), Except = { "Hunt", "Attack" } },
		{ To = "Investigate", When = When.New("HeardAt"), Except = { "Hunt", "Attack" } },
	},
	States = {
		Patrol = States.Patrol({ Points = "Nodes", Speed = 10 }),
		Investigate = States.Investigate({ Target = "HeardPosition", Speed = 14, Then = "Patrol" }),
		Hunt = { ... },
		Search = States.Search({ Around = "SeenPosition", Radius = 12, Points = 3, Duration = 14, Then = "Patrol" }),
		Attack = VluxyAI.Combat.Attack.State({ ... }),
	},
}

States.Roam walks the best point of an Interest map, marking each visited, so an enemy that has lost you checks the places you would plausibly be.

Every factory accepts Transitions (checked before the state's own logic, like any state), Enter and Exit hooks run after the built-in ones, Speed to set on entry, and Key, the agent.Data key its scratch lives under (default: the state's own name). Positions may be given as a blackboard or Data key, a Vector3, or a function of the agent. A point the navigator cannot reach is skipped on the next tick, so a search point inside a wall costs nothing but a failed plan.

Roam​

</>
States.Roam(options: RoamOptions) → State

Asks the Interest map for the best point, walks there, lingers, marks it visited, and asks again. Points the agent just visited score nothing, so it spreads its search. When no point scores, or Duration runs out, it enters Then.

interface GraphRoamOptions {
Graph: {GraphNode} | Graph | (agent: Agent) → {GraphNode}--

The nodes: a Graph pathfinder (its GetNodes), the node list, or a function. Required.

Pick: ((
agent: Agent,
nodes: {GraphNode},
current: number
) → number?)?--

The next destination's node index, from the node nearest the agent. nil stands still and asks again next tick. Default: any other node at random.

Pause: number | {number}?--

Seconds to stand at each destination, or a { min, max } range. Default none.

Speed: number?--

Set on entry.

Random: Random?--

For the default pick and a ranged Pause. Default agent.Data.Random, else a new one.

Key: string?--

The Data key for the route. Default "GraphRoam".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Roams an authored graph one node at a time. It picks a destination, routes to it with Graph.AStar from the node nearest the agent, and sends the agent to each node of the route in turn, starting the next leg only once the last one arrived. So the graph decides the order while the agent's own pathfinder plans every leg, unlike Hybrid, which walks the middle of a graph route straight. An agent off the graph walks to the nearest node first; a leg that fails re-plans from where the agent stands.

The route is kept at agent.Data[Key], for a brain or a debug view to read: Route (node indices), Leg (the index into Route being walked), Next (that node's index) and Goal. It survives leaving and re-entering the state, so an enemy that broke off to investigate resumes its leg.

Seconds to stare before Then. Default 4.

Then: string?--

The state to enter when the time is up.

Seconds after leaving during which When.Timer("States.<Key>Cooldown") is false, so a brain does not stare again at once. Default 0.

Face: boolean?--

Turn toward the target while staring. Off for a statue. Default true.

Speed: number?--

Random: Random?--

Key: string?--

Transitions: {Transition}?

Exit: ((agent: Agent) → ())?
}

Stops, and stares at something it cannot or will not reach: a player in a safe room, a light it will not step into. After Duration it moves on to Then; on the way out it starts the States.<Key>Cooldown timer for Cooldown seconds, which a transition into this state checks with When.Timer so the agent walks away instead of turning straight back.

interface BurrowOptions {
To: string | Vector3 | (agent: Agent) → Vector3?--

Where to come up, as a floor position, read once on entry: usually the Key of a Hideout sense. Required.

Then: string?--

The state to enter once it has risen, or at once when To has no position.

Depth: number?--

Studs it sinks under the floor. Default 7.

Time: number?--

Seconds to sink, and again to rise. Default 1.5.

Height: number?--

Studs above the floor its body ends up at. Default 3, a humanoid's root.

Key: string?--

Default "Burrow".

Transitions: {Transition}?
Enter: ((agent: Agent) → ())?
Exit: ((agent: Agent) → ())?
}

Vanishes and comes back somewhere else: stops, sinks Depth studs into the floor over Time seconds, moves under the To position, rises out of the floor there over another Time, and enters Then. For a statue that burrows, a ghost that fades through the floor, a creature that drops into a vent: pair it with Hideout so it only ever comes up where nobody is looking. A voice line or a sound keyed on this state's name covers the whole move.
