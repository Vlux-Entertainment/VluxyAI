Footsteps

Footstep audio from how far a rig actually walks. Exposed as VluxyAI.Animator.Footsteps (the client-side twin of Locomotion). Attach it to the rig a Replica moves and destroy it with the replica: 

-- client, in the game's replica setup
local steps = VluxyAI.Animator.Footsteps.Attach(replica.Entity, { Sound = 9114234567, Stride = 2.5 })
replica.Destroyed:Connect(function() steps:Destroy() end)

For the enemies to hear each other's steps, give the mover a Noise option; that is the server's business and this is the player's ears.

Types

interface FootstepsOptions {
Sound: Sound | number?--

A Sound to clone under the root, or an asset id to make one from. Leave it out with OnStep.

Stride: number?--

Studs of floor travel between steps. Default 3.

Volume: number?--

Applied to a sound made from an id. Default 0.5.

MinSpeed: number?--

Studs per second below which no steps play, so a nudge or a settle is silent. Default 0.5.

PitchVariation: number?--

Random spread of PlaybackSpeed around 1, so steps do not sound stamped. Default 0.1.

OnStep: ((
position: Vector3,
root: BasePart?
) → ())?--

Called on every step, with or without a Sound: pick a sound by material here.

Random: Random?--

For the pitch. Default a new one.

}

Watches the pivot every Heartbeat and plays a step each Stride studs of horizontal travel while the rig is moving faster than MinSpeed.
